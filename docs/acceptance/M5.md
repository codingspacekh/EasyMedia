## Notes

- **Unlink audio** (separating a clip's sound onto its own track) needs audio tracks, which arrive in M8; moved there. Remove sound (mute) is done.
- **Mutation check:** breaking the Remove sound checkbox made the 11b UI test fail (a 4.5 s audio track appeared), so the UI tests are meaningful.
- **Found while building:** the preview played the sound of clips marked "Remove sound" while the export did not — fixed so the preview matches the export.
- **Accessibility fixes from the tests:** timeline clips had their trim handles' labels in their spoken name; Fit choices had their hint text in theirs. Both now have clean names.
- Coverage: branch coverage first fell below 85 % because the Preview component had no tests (48 %); tests for each of its states were added (now 88 %).
