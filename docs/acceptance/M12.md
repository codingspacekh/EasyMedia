## Decisions made in M12

- **No paid code signing** for v1.0 (README §15, decision 8): the install guide shows the free way
  past Gatekeeper and SmartScreen. The Mac app is signed ad hoc, without the hardened runtime.
- **A DMG per Mac chip** instead of one universal DMG: 189 MB and 207 MB instead of 358 MB.
- **N6 raised to 220 MB** per installer (decision 9): Electron alone is about 134 MB compressed.
  Measured: Windows installer 173 MB; Mac 189 / 207 MB; the portable Windows zip is 235 MB (zip
  packs less tightly; it is not an installer). Every release build checks this.
- **Snapshots can be named** (the Bali paper asks for "Bali1" and "Bali2"; it could not be done in
  the app alone).
- **Space and Delete in Video mode too** (N10): only Audio mode had them.

## For the teacher: the checks only a person can do

Use the **installed** app (from the draft release, or an artifact of the release workflow), not
`npm run app`.

### A. Performance on the weakest laptop (N1–N5)

1. On the weakest Windows laptop (ideally 8 GB RAM), close other programs.
2. Start EasyMedia from a command prompt with the report switched on:
   `set EASYMEDIA_PERF_REPORT=%USERPROFILE%\Desktop\easymedia-performance.json` then
   `"%LOCALAPPDATA%\Programs\EasyMedia\EasyMedia.exe"`.
3. Make an exam-sized project (about 10 clips, up to 5 minutes, 1080p): import, wait for
   **Ready**, put them on the timeline, add a title, a transition and music.
4. Press Play and watch the preview for a minute (**N1**: smooth, ≥ 24 fps).
5. Export one minute of 1080p as MP4 and time it (**N2**: ≤ 3 minutes).
6. In Audio mode, apply Noise reduction and Change pitch to a 3-minute stereo song (**N3**: ≤ 3 s
   each).
7. Close EasyMedia. The report on the Desktop has the start-up time (**N5**: ≤ 5 s) and the
   highest memory use (**N4**: ≤ 600 MB). Send it to the maintainer.

### B. Full acceptance run, on a Windows 11 laptop and on a Mac

- Install from the downloads as a student would (INSTALL.md), including the SmartScreen / Gatekeeper
  steps and the microphone permission.
- Do the coursebook tasks (README §13) — Book A Activities 11.01–11.30, Book B Tasks 11a–11p and
  Activities 11a–11i — with the coursebook files, and check each output against the task.
- Do the **Bali practice paper** (Book B practice questions 1–7) with a timer, as in an exam.
- Package one project on Windows, open it on the Mac and export it there (and the other way).
- Note anything that does not work, is slow, or is hard to understand.
