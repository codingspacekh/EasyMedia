Tests: 8 new UI tests (filters, tracks, snap, transition button, zoom, safe area, new title tab); the M5 and M7 UI tests now open the Audio / Effects tab first. Found by the tests during the redesign: the toolbar no longer fitted the smallest window (fixed with a compact layout), and two buttons' names clashed with "Import" (renamed).

**Bug found by CI after the redesign (both Macs): the app sometimes could not quit.** The Book B 11g and Undo/Redo tests passed every check and then timed out closing the app. The CI traces showed all assertions green and the last step `app.close()`. Locally two problems were found:
1. Quitting left an FFmpeg job (a preview copy or the new thumbnail) running in the background, wasting the student's CPU. The job queue now has `cancelAll()`, called before the app quits.
2. A job that finished or was cancelled as the window closed sent its progress to the destroyed window; that throws in the main process, and Electron's error dialog then stops the app from exiting — an intermittent hang (also the likely cause of the single unexplained local E2E failure earlier). Events now go through `sendToWindow`, which does nothing for a closed window.
Regression tests: unit tests for `cancelAll` and `sendToWindow`, and an E2E test that quits while previews are being made (closes within 15 s, no FFmpeg left). Mutation check: without the closed-window guard the E2E test hung in 1 of 3 runs.

## Notes

- **Bug found by the E2E tests:** a plain cut followed by a transition could not be exported — `concat` gives its output a fine timebase (1/1 000 000) but `xfade` needs the frame timebase. The compiler now resets the timebase after each cut in a chain; a real-FFmpeg regression test was added. The unit test had only checked the filter text, and the first real-FFmpeg test happened to use transitions on every cut — a reminder that filter graphs must be run, not just read.
- **Mutation check:** making filters do nothing made the 11.12 blur test and the 11i cold-tone test fail.
- **Fixed in my own tests while reviewing:** the 11h "move to the final frame" step clicked outside the ruler and hid the error, so the snapshot was really taken at 0 s; it now clicks inside and checks that the dialog shows the last frame.
- **Labels:** a title slide now has both text fades (M6) and picture fades (M7); the text ones are renamed "Text fade in / out" so every field has its own name.
- **Interpretations:** Book A's "Additive Dissolve at the beginning of BeeFly" (the first clip) is a fade in from black — a transition needs a clip before it. One fade colour per clip, as in screen 06.
- **Approximate preview:** every transition previews as a blend (the export uses the real wipe, slide, circle…); filters preview as CSS filters.
- **Not built (minor):** "Apply to all cuts" for transitions (screen 05) and the "original clip size" option for snapshots (screen 09) — snapshots are at the project size.
- **TDD notes:** the generated-settings component (`EffectParams`) was written in the same step as its test, so the test was not seen failing first.
