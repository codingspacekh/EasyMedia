## Decisions and notes

- The grid attracts only while it is shown, so nothing jumps to lines the student cannot see.
- View settings (rulers, grid, snapping, open folders) are saved with the animation but are not edits: no undo step, no "unsaved changes".
- Text boxes are measured by the screen when the words, size or font change; in tests (no canvas) a rough measure is used.
- Pen paths are straight-sided in M13; curve handles and path editing come with motion paths in M15.
- Pictures can be placed (AN5's import); tracing arrives in M16.
