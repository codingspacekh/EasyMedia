## Decisions (the maintainer, 2026-11-04)

- **Picture on a picture** is made in the picture dialog and saved as a new picture, not as an
  overlay track on the timeline: it is what the paper asks, and keeps the timeline as it is.
- **The pilot is v1.5.0**, after v1.4.0 (M16 + M16b) is tagged once the teacher has checked M16b.
- **The GitHub repo is renamed OneEditor** before the pilot, as the update address is built in.
- **Macs are in the pilot**, signed with the maintainer's own certificate as the gradebook is.
