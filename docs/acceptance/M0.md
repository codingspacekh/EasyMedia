## How to measure on a Windows laptop

### Easiest: ready-made package (nothing to install on the laptop)

1. On the teacher's Mac: `gh workflow run spike-bundle.yml --ref main`, wait ~5 min, then `gh run download --name EasyMedia-M0-spike-windows --dir EasyMedia-M0-spike` (or Actions tab → *M0 spike bundle* → download the artifact).
2. Copy the `EasyMedia-M0-spike` folder to the laptop (USB stick or shared drive), as a zip if easier.
3. On the laptop: close other programs, double-click `1-run-performance-test.bat`. If Windows SmartScreen appears: **More info → Run anyway**.
4. When the window closes, bring back `report.json` and paste its numbers into the table above.
5. Optional: `2-try-your-own-video.bat` → import a real coursebook clip, play it, export it, and note whether it feels smooth.

### Alternative: from source

```bash
npm ci
npm run fetch:ffmpeg
npm run fixtures -- --group spike --out spikes/m0-electron/out
npm run spike -- --auto spikes/m0-electron/out/spike_1080p30_60s.mp4 --report spikes/m0-electron/out/report.json
```

**Decision rule:** if any target fails on the weakest laptop, stop and revisit the architecture before M1 (e.g. lower proxy resolution, Tauri, or a hardware-encoder-only export path).
