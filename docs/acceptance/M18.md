## Notes

- Graphics mode is built on Animation mode, so its tools are the ones the teacher has checked
  in M13–M17a: no new drawing code; the vector layers are animation layers.
- A canvas of a print size (A4 at 300 dpi) is drawn scaled down on the stage, as a big stage
  is; exports draw it at full size.
- An animation can be opened in Graphics mode by renaming it `.mveg`; it is shown as a screen
  picture (96 dpi, px) of its first frame. Not offered in the menus.
- The teacher notes gain syllabus 19.1 and 19.2 with the points the Graphics tab teaches so far
  (layers, align and distribute, colour systems, resolution, export, a vector graphic for its
  use); the rest of 19 joins as M19–M23 add its tools.
- Help ▸ About OneEditor (the OneEditor menu on a Mac): version, "© 2026 CodingSpaceKH. Free
  software under the GNU GPL v3." and the website for contributors, codingspacekh.dev, which the
  main process opens in the browser (only that address: IPC `app:website`, `core/about.ts`). The
  installers' copyright reads "Copyright © 2026 CodingSpaceKH · GPL-3.0".
- CI's first run on `m18` failed on branch coverage (84.33 % < 85 %): the Graphics screens'
  keys, toolbar, Image settings, export sizes and HSL / CMYK numbers had no tests. Their tests
  found a bug: changing Image settings' units set the height to 0 (it was worked out after the
  width had changed, from the new width in the old unit). `npm run check` now applies the
  coverage thresholds, as CI does.
- CI's second run: on Windows, Audio mode's Export went past the window's edge at 1100 × 700
  (the header was 1187 px: the fourth mode button). In a window under 1300 px wide the modes not
  chosen now show only their icon (their name in the tooltip and for screen readers); a test
  checks every mode's header fits at 1100 × 700. A 1366 px laptop still shows all four names.
