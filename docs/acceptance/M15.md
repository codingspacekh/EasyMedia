## Decisions and notes

- **Several paths per object**, in frame order and never overlapping. Task 6 needs a computer to go out along one path and back along another; one path per object (as planned) could not do it.
- **Masks work on the layer directly beneath**, as in the coursebook ("the layer beneath automatically becomes a sub-layer of the mask"). The plan said everything beneath down to the next mask; that would also have masked question 2's logo and sentence.
- **On the stage a mask works while its layer is locked** (the coursebook's padlock), so its shapes can be seen and moved while unlocked. Exports always apply it.
- **A pen path shows its points instead of the box's handles**; its size and turn stay in the Properties panel. Seen in the real app: the handles sat on top of the points.
- **Morph into… removes the shape it picks** (one undo step brings it back), keeps a gradient fill as drawn, and only tweens solid colours.
- **A text box follows its font size** from its top-left corner, so the outline matches the letters while the size tweens (Task 6's shrinking introduction).
- **Fixed:** frame 0 was drawn as "no frame", so the first frame of every export ignored motion paths. Found by the end-to-end test.
- Coursebook 19.05.5 (each letter morphing into the next) needs text turned into shapes, which is not built: text cannot morph.
