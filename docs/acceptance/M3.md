## Notes and decisions

- **Stand-in media.** `Lake_Naivasha.mp4` → a 20 s 1080p fixture whose **brightness rises with time**, so tests can tell which moment of the source a frame came from. FFmpeg's test pattern repeats too much for this (frames 8 s apart differ by about 1 brightness level).
- **Mutation checks.** Breaking the trim start point kept the length correct (4.5 s) — only the brightness check caught it. Making "letterbox" behave like "crop" was caught by the black-bar pixel check. Both tests are therefore meaningful.
- **No audio stream when nothing has sound.** Matches Book B's "remove all sound": the file has no audio track at all, rather than a silent one.
- **Every segment's sound is padded/trimmed to its picture length**, so later clips never drift out of sync.
- **Refusals, not silent omissions.** Projects with captions/credits, music/voiceover tracks or title text are refused with a clear message until M6 / M8 add them.
- **Usage pause.** Work stopped once mid-milestone (checkpoint commit `1f47812`, green in CI) and resumed the next day.
