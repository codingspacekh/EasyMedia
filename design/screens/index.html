Import into Figma

  1. Install the free html.to.design plugin in Figma, and its Chrome extension.
  2. Serve this folder locally: python3 -m http.server 8000 --directory design/screens
  3. Open a screen in Chrome (e.g. http://localhost:8000/01-video-editor.html) and import it with the extension; or paste the URL into the plugin if it can reach it.
  4. Set the import viewport to 1520 px wide so each 1440 × 900 frame comes in whole.
  5. Import 23 · Design system first; turn its colours and text styles into Figma styles, then import the other screens.

Editing the screens

  1. Edit the templates in design/src/ (shared parts are in design/src/partials/, colours in styles.css).
  2. Rebuild: python3 design/build.py → output goes to design/screens/.
