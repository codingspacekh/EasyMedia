Two meanings of "compression"
Dynamic range compression
This effect. Makes the loudest parts quieter so the whole clip sounds more even. File size does not change.
File compression
Happens when you export (MP3, AAC, FLAC). Makes the file smaller: lossy removes data for ever, lossless keeps it all.
{{i:info}}
Why compress dynamic range? A voiceover with some words very loud and others very quiet is hard to follow. Compression evens it out, so it can be heard clearly over music or in a noisy place. Too much makes it sound flat and lifeless.
